# Changes, 25 October 2026: Wheelio becomes WashKrew

For the engineer picking this up. Branch: `staging`. Commits: 56cd650, 13f40a1, 063d71d, 327c9a6.

## 1. What changed
- **Name:** WashKrew everywhere a person can see it. Flutter uses `Brand.name` (`WashKrew`) and
  `Brand.captainApp` (`WashKrew Captain`) from `packages/washkrew_ui/lib/src/tokens.dart`; never type the name.
- **Phone:** iOS display names are `WashKrew` and `WashKrew Captain` (Info.plist), new app icons (Customer: mark
  on white; Captain: white mark on charcoal) and launch images.
- **Logo:** masters (SVG) in `brand/`; PNGs at 1x/2x/3x in `packages/washkrew_ui/lib/brand/`. Show the logo only
  through the `WLogo` widget (`lockup`, `wordmark`, `mark`; light/dark). Used on the Customer splash (lockup, 96),
  Customer home header (`BrandMark`), Captain language screen (48) and the live-mode Captain header (36).
- **Colours:** follow the logo: primary `#0049FF`, heading charcoal `#22282D`.
- **Code:** packages renamed to `washkrew_ui` and `washkrew_firebase`; `WashKrewRuntime`, `launchWashKrew`,
  `WashKrewFirebase`, `WashKrewRepository`, backend `WashKrewService`. Razorpay checkout name is `WashKrew`
  (backend source; takes effect on the next Functions deploy). Hosting page uses the new wordmark.

## 2. Left as `wheelio` on purpose
Bundle IDs `com.amanmaheshwari.wheelio.*`, Firebase project `wheelio-apps`, the `WHEELIO_DEMO` define,
`apps/ios/Wheelio.xcodeproj`, repo and folder names. Changing them needs new App Store / Firebase setup.
`apps/web` (paused), `legacy/` and `designs/` are untouched.

## 3. Checks
`flutter analyze` clean in both apps, 4 Customer tests pass, backend `.mjs` files parse. Every gallery screen in
both apps was screenshotted at 390×844 (80 Customer, 77 Captain) to check logo size and placement; no problems.
After pulling, run `flutter pub get` in each app (package names changed), then `pod install` in `ios/`.
