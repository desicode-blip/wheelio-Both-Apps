## 5. Phone install pitfall (found 25 Oct)
Xcode's Run for the Customer workspace kept installing `apps/flutter/customer/build/ios/iphoneos/Runner.app`,
a stale **debug** build left by live mode (`tool/live.sh`, i.e. `flutter run`) on 24 Oct, instead of the
fresh release build it had just compiled into DerivedData. So the phone kept getting "Wheelio" with the Flutter
icon even though the code and the Xcode build were correct. Evidence: Xcode's install error
(CoreDeviceError 3002) named that path once the folder was moved, and the console showed
"Dart execution mode: JIT" (debug engine) on every run.
Fix used: the fresh, signed release `Runner.app` was copied to that path and installed.
To avoid it: after using live mode, install with `apps/flutter/tool/run-ios.sh <app>` (it rebuilds
`build/ios/iphoneos` in release and installs it), or in Xcode use Product > Clean Build Folder before Run.
The stale build was moved to `apps/flutter/customer/build-stale-2026-10-24/` (not tracked; safe to delete).
