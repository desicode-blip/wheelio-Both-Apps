# washkrew_ui

Shared WashKrew design system and app shell for the Flutter Customer and Captain apps: colour and type tokens, icons, components, navigation stack, phone frame and device services (sound, notifications, voice, photos, calls).

The current design source is pinned to Git `af036f0`; the original SwiftUI provenance remains in Git history. See [docs/FLUTTER.md](../../../../../docs/FLUTTER.md).
