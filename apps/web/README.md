# Wheelio website

Next.js App Router application with TypeScript, local Roboto fonts and a basic responsive landing page. Run `pnpm dev`, `pnpm typecheck` and `pnpm build` from the repository root.

- `src/app/page.tsx`: landing page content and sections.
- `src/app/layout.tsx`: shared layout, font loading and metadata.
- `src/app/globals.css`: responsive styles and brand tokens.
- `src/components/`: reusable brand and wash illustration.
- `public/`: place future static assets here.

Booking and app downloads will be added later. The current calls to action navigate within the page; no form collects data and no backend connection is required.
